# Generated contracts

Five generators own checked-in code. Each is a package under `tools/codegen/`,
run as `python3 -m tools.codegen.<name>` **from the repository root**, and all
accept `--check`. Never hand-edit an output: CI fails on a stale one, and
`docs/configuration-schema.md` and `docs/telemetry-catalog.md` are byte-compared
too. Generators emit no comments beyond the `Generated by … Do not edit.`
banner.

- `configuration_schema` — `configuration/configuration_schema.json` →
  `firmware/services/configuration_contract/include/application_configuration_generated.hpp`,
  `firmware/services/configuration/include/configuration_schema_generated.hpp`,
  `configurator/src/shared/configuration-schema.ts`,
  `docs/configuration-schema.md`. The schema's `documents` block must partition
  every serialized root section; the generator emits the enum, the key
  allow-lists, the bounds and the restart flags for both sides.
  `tools/codegen/configuration_schema/markdown.py` hardcodes the links to
  `device-configuration.md` and `control-protocol.md`.
- `telemetry_catalog` — `telemetry/telemetry_catalog.json` and
  `telemetry/simhub_generic_mappings.json` →
  `firmware/services/telemetry/include/telemetry_catalog_generated.hpp`,
  `firmware/services/telemetry/protocols/simhub/include/simhub_catalog_generated.hpp`,
  `configurator/src/shared/telemetry-catalog.ts`,
  `configurator/src/shared/simhub-profile-data.ts`, `docs/telemetry-catalog.md`,
  `simhub/SimCore-telemetry.shsds`. Regenerate all consumers together.
- `led_font` — `fonts/led_bitmap_font.json` (four faces as rows of `#` and
  space) → `firmware/components/led/include/led_font_generated.hpp` and
  `configurator/src/shared/led-font.ts`; both sides need the same glyphs.
- `font_catalog` — `fonts/google_fonts_snapshot.json` and
  `fonts/google_fonts_selection.json` →
  `configurator/src/main/font-library/google-fonts-catalog.json`, read lazily in
  the main process and never bundled into JS. `--refresh` re-fetches the
  snapshot; without it the generator is offline and deterministic.
  `fontFamilyId()` in `configurator/src/shared/font-library.ts` is the single
  id implementation; the generator only checks that every derivable id is valid
  and unique.
- `ui_strings` — `i18n/en.json` → `configurator/src/shared/ui-string-keys.ts`
  (the `UiStringKey` union and the parameter types) and
  `configurator/src/shared/ui-strings-en.ts` (the table, an explicit
  `Readonly<Record<string, string>>` so no project builds a literal type over
  the catalog). Code reads them through `t()` in
  `configurator/src/shared/ui-text.ts`. A plural message carries a `$plural`
  object of CLDR categories selected by `Intl.PluralRules`, placeholders are
  `{name}`, and `$note` is data for the translator (ADR 0031).
